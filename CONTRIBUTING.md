# Contributing to Laura

Thanks for wanting to contribute! We welcome contributors of all skill levels. To make contributions easy to review and land, please follow these guidelines.

Getting started

1. Fork the repo and create a branch from the default branch for your change (feature/my-feature or fix/issue-123).
2. Keep changes focused and small — one logical change per pull request.
3. Run any tests and linters before opening a PR.

Development environment

- Check for a README or docs/ with setup instructions. If none exist, run the project locally and document the commands you used.
- Use standard formatting tools for the project's language (prettier, black, eslint, etc.) if configured.

Pull request process

- Open a PR against the default branch from your feature branch.
- Use a descriptive title and include a short summary of what the change does.
- Link any related issues (Fixes #123).
- Add tests where appropriate.

Code of conduct

Please be respectful and follow community standards. (Consider adding a CODE_OF_CONDUCT.md file to the repo.)

Maintainers

The maintainers will review PRs and may request changes. We aim to respond within a few days.
